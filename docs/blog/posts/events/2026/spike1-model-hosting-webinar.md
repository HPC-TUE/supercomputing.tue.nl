# Spike-1 Model Hosting: Webinar & Q&A

Curious about using hosted LLMs at TU/e — or how to get more speed out of them? Join the TU/e Supercomputing Center
(SCC) for a **one-hour webinar** on the **Spike-1 LLM hosting service** supported by EAISI: a walkthrough of the
gateway, a look under the hood of the inference stack, and two live Q&A rounds.

<!-- more -->

## What we'll cover

- **Getting started & updates.** Models, API keys, the usage dashboard and token budgets, plus the latest changes to the
  service.
- **Under the hood.** What SM cores are, how we implemented KV caching, and how optimising SM-core utilisation delivered
  an **8× speed-up**.
- **Live Q&A.** Two dedicated slots for your questions, one after each part of the programme.

## Practical information

- **When:** Tuesday 8 December 2026, 13:00–14:00 CET.
- **Where:** Microsoft Teams. Use the join button on this page.
- **Language:** English.
- **Admission:** free. Open to everyone at TU/e.
- **Contact:** [supercomputing@tue.nl](mailto:supercomputing@tue.nl)
